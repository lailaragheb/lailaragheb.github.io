HOW TO PUT THIS ONLINE WITH GITHUB PAGES

1. Create a PUBLIC repository named exactly: lailaragheb.github.io
2. Click "uploading an existing file" and drag in everything INSIDE this folder (not the folder itself).
3. Commit the changes.
4. Settings > Pages > Deploy from a branch > main > / (root) > Save.
5. After a minute or two the site is at https://lailaragheb.github.io

The preview image address is already set to https://lailaragheb.github.io/og.png

Upload a new file named Laila_Ragheb_Resume.pdf to the repository (it overwrites the old one).
