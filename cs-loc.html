Localizing 22 Payments Website Screens Into Arabic in 3 Days

Context
Freelance project for a payments company
Role
Content Designer, Arabic content
Scope
22 website screens, English to Modern Standard Arabic, in 3 days
Team
Handed over to the client's design team
Tools
Figma and Figma's AI agent
Status
Delivered. The Arabic website hasn't launched yet.
ProblemA payments company's website mockups existed only in English, and the Arabic site needed them in Arabic.
What I didI put all 22 screens in one Figma file, extracted the text with Figma's AI agent, wrote the Arabic, and handed it over as a table.
Result22 screens delivered in 3 days, and the client was impressed by how organized the handoff was.

The brief

The company's website mockups existed in English only. They needed Arabic versions for the Arabic site, as a straight translation, so the design team could swap the copy in and adjust each screen for right-to-left layout.

The approach

The work was really a workflow, so I built it to be easy to hand off.

  1. One file. I put all 22 screens into a single Figma file, so every screen and its copy lived in one place.
  2. Extraction. I used Figma's AI agent to pull every text node from each screen into a table placed beside it. Nothing was retyped and nothing was missed.
  3. Translation. I wrote the Arabic for each string in Modern Standard Arabic, in a column next to its English source.
  4. Handoff. The design team replaced the English with the Arabic straight from the table and adjusted the layouts for RTL.

Small decisions in the table

  • Universal formats stayed as they are: the email and phone placeholders, the country code, the card number, MM/YY, and CVV.
  • Example text was localized. The sample name "Youssef Bsheer" became "يوسف بشير".
  • Matching the register to the brief. This brief asked for a straight translation, so I wrote in Modern Standard Arabic. When a brand has a defined voice, I match the register to it. For a digital bank I worked with, that meant moderate Egyptian Arabic.

The result

The company's feedback was very positive, and they were particularly impressed with how organized the handoff was. The Arabic website hasn't launched yet.
